# BCI_Link_Start

**궁극적 목표: 완전몰입 가상현실(풀 다이브 VR) 구축**

이 저장소는 풀 다이브 VR을 향한 조사 기록과, 지금 기술로 만들 수 있는 첫 번째 프로토타입(비침습 꿈 활용 방식)의 설계를 담고 있다.

## 핵심 결론

1. **전뇌화(마인드 업로딩)는 현재 불가능**하며, 풀 다이브에 꼭 필요하지도 않다.
2. 풀 다이브의 실제 경로는 **고대역폭 양방향 BCI**(뇌에 감각을 쓰고, 운동 의도를 읽는 인터페이스)다. 현재는 의료용 초기 단계다.
3. 지금 비침습으로 가장 가까운 체험은 **꿈(자각몽) 활용**이다. 뇌는 꿈을 꿀 때 이미 몸을 차단하고 완전한 가상 세계를 만든다.
4. 꿈의 휘발 문제는 **외부 저장 + 기상 직후 리플레이**로 상당 부분 해결할 수 있다. 진짜 병목은 **꿈 내용 통제**다.
