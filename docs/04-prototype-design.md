# 04. 프로토타입 설계 — 꿈 퀘스트 + 외부 세이브

**목표**: 꿈속에서 퀘스트를 수행하고, 진행 상황을 외부에 기록하고, 아침에 리플레이로 기억을 살린다.
**방식**: 전부 비침습 (소리·빛·진동만 사용)
**예산**: 약 80~120만 원

## 1. 전체 구조

```
[잠들기 전]  퀘스트 선택 + 소리 단서 학습 + 눈 신호 연습
      ↓
[수면 중]   뇌파/눈 센서 → 렘수면 감지 → 단서 재생 → 자각몽 유도
      ↓
[꿈속]      눈동자 신호(LRLR)로 "자각했어" / 퀘스트 응답
      ↓
[외부 PC]   모든 이벤트를 시간순 기록 (= 게임 세이브)
      ↓
[기상 직후] 음성 꿈 보고 → 자동 받아쓰기 → 타임라인 리플레이
```

## 2. 하드웨어

| 부품 | 역할 | 추천 | 대략 가격 |
|---|---|---|---|
| 뇌파·안구 센서 | 렘 감지, 눈 신호 | OpenBCI Ganglion + 이마·눈가 전극 | 60~70만 원 |
| (대안) 수면 헤드밴드 | 동일, 착용 편함 | ZMax, Muse S | 기종별 상이 |
| 소리 출력 | 단서, 퀘스트 신호 | 베개 스피커 / 골전도 이어폰 | 3~5만 원 |
| 빛·진동 | 보조 단서 | 수면 안대 + LED + 진동모터 + Arduino | 3~5만 원 |
| 마이크 | 기상 후 음성 보고 | 아무거나 | - |
| 컴퓨터 | 실시간 처리 | 노트북 / 라즈베리파이 5 | 보유품 |

**센서 위치**: 눈 양옆 바깥쪽(관자놀이 쪽)에 전극 한 쌍 → 좌우 눈동자 움직임(수평 EOG)이 선명하게 잡힘.

## 3. 소프트웨어 (Python)

| 모듈 | 역할 | 도구 |
|---|---|---|
| ① 수집 | 실시간 센서 데이터 | BrainFlow |
| ② 수면 단계 판정 | 렘 감지 | 실시간: 규칙 기반 + 경량 모델 / 사후 검증: YASA |
| ③ 단서 컨트롤러 | 렘 안정 시 단서 재생, 각성 징후 시 중단 | 자체 구현 |
| ④ 눈 신호 해석 | LRLR 패턴 감지, 응답 코드 해석 | 자체 구현 |
| ⑤ 이벤트 로그 | 타임스탬프 이벤트 저장 | SQLite / JSON |
| ⑥ 기상·리플레이 | 음성 받아쓰기, 타임라인 UI | Whisper + 웹 UI |

### 렘수면 판정 규칙 (초기 버전)
- 빠른 안구 운동이 잦음
- 근육 신호 낮음 (이마 전극 고주파 성분으로 추정)
- 뇌파가 빠르고 진폭이 낮음 (각성과 유사)
- 위 상태가 **3분 이상 지속**되면 렘 확정 → 단서 재생

### 꿈속 통신 프로토콜 (예시)

| 눈 신호 | 의미 |
|---|---|
| 좌우좌우 (LRLR) | 자각함 (세션 시작) |
| 좌우 1회 | 예 / 다음 |
| 좌우 2회 | 아니오 |
| 좌우좌우좌우 | 퀘스트 완료 |

시스템 응답: 높은 음 = 확인, 낮은 음 2회 = 다음 단계.

## 4. 수면 전 루틴

1. **단서 학습 (10~15분)**: 특정 소리·빛 → "지금 꿈인가?" 확인 연습. 표적 자각 재활성화(TLR, Carr 외 2020, 노스웨스턴대) 방식
2. **퀘스트 장면 학습**: 퀘스트(예: "등대에 올라가 열쇠 찾기") 이미지와 고유 배경음을 묶어 학습 → 수면 중 내용 유도 단서
3. **눈 신호 보정**: 깬 상태에서 LRLR 수행, 신호 크기 기록
4. **WBTB**: 5~6시간 수면 후 잠깐 깼다가 다시 잠들기 (새벽 렘이 길어 성공률 상승)

## 5. 로드맵

| 단계 | 기간 | 목표 | 성공 기준 |
|---|---|---|---|
| 0. 기록만 | 1~2주 | 단서 없이 밤새 기록, 렘·눈 신호 감지 검증 | 실시간 렘 판정과 YASA 사후 분석 80% 이상 일치 |
| 1. 자각 유도 | 2~4주 | 렘 중 단서 재생 | 자각 신호(LRLR) 확인된 밤 발생 |
| 2. 양방향 통신 | 1~2개월 | 꿈속에서 시스템 질문에 응답 | 예/아니오 정확도 측정 |
| 3. 퀘스트 + 세이브 | 이후 | 퀘스트 진행 외부 저장, 아침 리플레이 | 완료 신호 + 회상 점수 향상 |

**지표**: 렘 감지 정확도, 자각 성공률, 신호 인식률, 아침 회상 점수(1~5 자가 평가 + 로그 일치도).

## 6. 안전 수칙

- **배터리 전원만 사용.** 몸에 붙인 장비를 콘센트에 연결하지 않는다
- **뇌에 전기·초음파 자극을 DIY로 하지 않는다.** 이 설계는 소리·빛·진동만 사용
- **수면 부족 주의**: 실험은 주 2~3일
- 가위눌림·거짓 각성이 늘 수 있음. 불편하면 즉시 중단
- 수면 장애나 정신건강 이슈가 있으면 전문가와 먼저 상의

## 7. 기대치

- 자각몽 유도 성공률은 연구에서도 수십 % 수준, 개인차 큼
- 3단계는 개인 프로젝트로서 연구 최전선과 비슷한 수준
- 퀘스트 내용 주입은 "유도"에 그침. 진짜 가치는 **데이터 축적**: 어떤 단서가 어떤 꿈을 만드는지가 다음 단계 연구 재료가 된다
