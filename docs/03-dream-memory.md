# 03. 꿈 활용과 기억 휘발 문제

## 문제

꿈은 깨면 잊힌다. 플레이 경험이 휘발되면 게임으로서 의미가 사라진다.

## 꿈은 왜 휘발되는가

- **저장 신호 부재**: 렘수면 중 노르에피네프린(“저장하라” 신호 역할)이 거의 사라짐
- **해마 → 장기 기억 전달 약화**
- **각성 구간 부재**: 꿈을 잘 기억하는 사람은 수면 중 짧은 각성이 잦고, 그때 꿈이 저장됨

즉 경험은 일어났지만 **저장 단계**가 막혀 있다. 저장만 시키면 된다.

## 해결 방향

### 1. 실시간 외부 기록 (가장 중요)
- Konkoly 외(2021, Current Biology): 자각몽 중인 사람과 실시간 대화 성공. 소리로 낸 산수 문제에 꿈속에서 눈동자 움직임으로 답함
- **설계 원칙**: 플레이 결과(진행, 선택, 획득)는 뇌가 아닌 **외부 시스템**에 저장. 뇌가 잊어도 게임 데이터는 남는다

### 2. 기상 직후 리플레이
- 꿈 일기가 회상률을 높이는 것과 같은 원리
- 깨자마자 로그·요약·음성 기록을 보여주면 흐릿한 기억이 재활성화되어 저장됨

### 3. 마이크로 각성 ("세이브 포인트")
- 중요한 장면마다 수 초간 얕게 각성시켜 저장 유도
- 소리·진동으로 수면 깊이를 조절하며 완전히 깨우지 않는 것이 핵심

### 4. 표적 기억 재활성화(TMR)
- 학습 시 들은 소리·냄새를 수면 중 다시 제시하면 해당 기억이 강화됨
- 게임 장면마다 고유 사운드를 부여해 회상 단서로 사용

> 갈란타민 등 약물이 자각몽·꿈 회상을 늘린다는 연구도 있으나 처방약이므로 자가 사용은 권장하지 않음.

## 휘발보다 더 큰 문제: 내용 통제

- 꿈은 내 뇌가 생성. 외부에서는 소리·빛·진동 단서로 약하게 영향만 줄 수 있음
- 게임 규칙·일관된 세계 유지가 어렵고, 멀티플레이는 현재 사실상 불가능
- 따라서 구조는 **"외부 시스템이 진짜 세계(상태)를 갖고, 꿈은 그것을 렌더링하는 화면"** 이어야 함
- 꿈에 정보를 넣는 대역폭을 키우는 것이 핵심 과제 → 초음파 등 비침습 자극 기술과 연결

## 요약

| 문제 | 해결 가능성 |
|---|---|
| 기억 휘발 | 높음 (외부 저장, 리플레이, 마이크로 각성) |
| 꿈속과의 통신 | 초보 수준이지만 실증됨 |
| 내용 통제 | 낮음, 핵심 연구 과제 |
| 멀티플레이 | 현재 매우 어려움 |
